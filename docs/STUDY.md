# 시스템 학습 가이드

## 1. 왜 이 시스템이 필요한가
영림 주문 데이터를 반복적으로 확인하고 정리하는 작업은 시간이 많이 들고 실수 가능성도 큽니다. 이 시스템은 주문 데이터를 자동으로 수집하고 변환한 뒤, 운영자가 빠르게 처리할 수 있도록 시트 허브 중심 흐름을 제공합니다.

---

## 2. 핵심 흐름

### 수집
- 영림 OMS에서 주문서와 견적서를 자동 수집합니다.

### 변환
- `local_file_processor.process_html_content()`가 HTML/MHTML을 ERP 형식 행 데이터로 변환합니다.

### 허브 저장
- 변환된 결과를 `Sheet1`에 자동 저장합니다.
- `복사` 버튼으로 클립보드 복사를 수행합니다.
- 5초 뒤 `Sheet2`에 append-only 이력을 기록합니다.
- `Sheet3`에는 날짜/건수/파일명이 남습니다.

### 완료 처리
- 운영자가 `완료` 버튼을 누르면 `Sheet1`을 비우고 락을 해제합니다.

---

## 3. 설계 포인트
- 직접 ERP 자동입력보다 운영 추적과 다중 사용자 충돌 방지에 초점을 둡니다.
- `Sheet1`의 상태/처리자/처리시작시간이 실시간 허브 메타데이터 역할을 합니다.
- 락 타임아웃 1분 규칙으로 장시간 점유를 자동 복구합니다.

---

## 4. 기억할 점
- 과거 문서의 `ERP Uploader`, `웹자료올리기`, `transformer.py` 표현은 현재 기준 주 경로가 아닐 수 있습니다.
- 현재 기준 변환 진입점은 `local_file_processor.process_html_content()`입니다.
- 현재 기준 운영 경로는 Google Sheet Hub 입니다.
