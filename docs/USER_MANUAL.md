# 사용자 매뉴얼

## 1. 개요
이 시스템은 영림 주문서 HTML/MHTML 파일을 수집하고 변환한 뒤, 결과를 **Google Sheet Hub**로 보내 운영자가 복사/완료 방식으로 처리할 수 있게 해 줍니다.

---

## 2. 사용 전 준비
- Windows PC
- Python 실행 환경
- 영림 OMS 접속 가능 브라우저
- Google Sheets 인증 파일과 토큰

---

## 3. 기본 사용 흐름

### 1단계: 서버 실행
- Flask 대시보드를 실행합니다.
- 기본 대시보드 주소는 `http://localhost:5080` 입니다.

### 2단계: 주문 수집
- 자동 다운로드 또는 수동 다운로드를 실행합니다.
- 수집된 파일은 READY 상태가 됩니다.

### 3단계: 복사
- 대시보드에서 `Ledger` 또는 `Estimate`의 `복사` 버튼을 누릅니다.
- 시스템이 변환 결과를 `Sheet1`에 자동 저장합니다.
- 같은 데이터가 클립보드에도 복사됩니다.
- 상태는 `처리중`으로 바뀝니다.

### 4단계: 이력 저장
- 복사 후 약 5초 뒤 동일 데이터가 `Sheet2`에 append-only 방식으로 기록됩니다.
- `Sheet3`에는 날짜/건수/파일명이 로그로 남습니다.

### 5단계: 완료
- 운영자가 작업을 마친 뒤 `완료` 버튼을 누릅니다.
- `Sheet1`이 비워지고 상태는 `완료`로 바뀝니다.
- 락이 해제되어 다음 작업이 가능해집니다.

---

## 4. 락 규칙
- `처리중` 상태일 때 다른 사용자의 복사 버튼은 비활성화됩니다.
- `처리중` 상태가 1분 이상 유지되면 자동으로 락이 해제됩니다.

---

## 5. 주의사항
- 현재 기본 운영 흐름은 ERP 직접 자동업로드가 아니라 Google Sheet Hub 방식입니다.
- `Sheet1`은 현재 처리용, `Sheet2`는 누적 이력, `Sheet3`는 로그 용도입니다.
- 인증 파일이 없거나 Google Sheets 접근이 안 되면 시트 저장이 실패할 수 있습니다.
