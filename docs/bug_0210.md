# Selenium 자동화 실행 불가 문제 요약 (shop_50)

## 1. 문제 개요

영림 자동화 시스템(shop_50)에서  
브라우저는 실행되지만 **다운로드가 시작되지 않고**,  
`data/youngrim_session.json` 세션 파일이 생성되지 않는 문제가 발생함.

---

## 2. 최초 증상

- `start_all.bat` 실행 시
  - Edge 브라우저는 정상 실행
  - DevTools listening 로그 출력
- 그러나:
  - 다운로드 루프 미시작
  - 세션 파일 미생성
  - `SessionNotCreatedException` 발생

---

## 3. 원인 분석 흐름

### 3.1 세션 관련 진단
- Headless 모드에서는 로그인 세션 생성 불가
- `restart_edge_with_login.bat` 실행 필요
- 그러나 로그인 후에도 `youngrim_session.json` 생성 ❌

➡️ **로그인 문제 아님**

---

### 3.2 Selenium 에러 핵심 로그
SessionNotCreatedException
Failed to establish browser connection


➡️ WebDriver 세션 자체가 생성되지 않음

---

### 3.3 Edge 환경 점검 결과

CMD 기준 확인:

- `msedge --version` ❌
- `where msedge.exe` ❌
- `C:\Program Files\Microsoft\Edge\Application` 경로 ❌
- 존재 파일: `.pma` 등 Store 내부 데이터만 존재

➡️ **결론**
- 해당 PC의 Edge는 **Microsoft Store(AppX) 버전**
- `msedge.exe` 실행 파일 없음
- Selenium에서 **Edge 사용 불가**

---

## 4. 핵심 결론

### 🔴 문제의 본질
- 실행/코드/설정 문제가 아님
- **로컬 PC 브라우저 환경 제약 문제**

### ❌ 불가능한 것
- Store Edge + Selenium
- Edge 기반 세션 생성

### ⭕ 가능한 것
- 설치형(Desktop) 브라우저 + Selenium

---

## 5. 최종 해결 방향 결정

### 선택지 비교

| 선택지 | 내용 | 평가 |
|------|------|------|
| A | Chrome + chromedriver 전환 | ✅ 선택 |
| B | 다른 PC에서 Edge 세션 생성 후 복사 | ⚠️ 임시 |

➡️ **선택 A 확정**

---

## 6. 현재 상태

- Edge: Store(AppX) 버전만 존재
- Chrome: 설치 안 됨
- Selenium 실행 불가 상태

---

## 7. 다음 단계 (확정)

1. **설치형 Chrome 다운로드 및 설치**
   - Store ❌
   - MSI / EXE 설치형만 허용
2. `where chrome.exe` 로 설치 확인
3. Chrome 버전에 맞는 chromedriver 연동
4. Selenium 실행 전환
5. 로그인 → `data/youngrim_session.json` 생성
6. 자동 다운로드 정상 시작

---

## 8. 한 줄 요약

> **문제는 코드가 아니라 PC 브라우저 환경이다.  
> Store 브라우저는 Selenium에서 사용할 수 없다.**
