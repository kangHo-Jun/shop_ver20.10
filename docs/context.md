# 작업 맥락

## 진행 중인 것

- 목재 플래그코드가 추가되었습니다.
  - 이제 `목재`는 `W`, `목재 슬림형`은 `WS`, `목재 와이드형`은 `WW`로 코드가 만들어집니다.
- 프레임몰딩 코드 규칙이 정리되었습니다.
  - `PVC`가 적혀 있으면 `PP` 코드가 붙습니다.
  - `PVC`가 없으면 `MDF`로 보고 `PM` 코드가 붙습니다.
  - `MDF` 표시가 빠진 프레임몰딩은 품목명에 `MDF`를 자동으로 넣어 줍니다.
