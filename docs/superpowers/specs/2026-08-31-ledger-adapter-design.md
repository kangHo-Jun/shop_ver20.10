# 원장 22열 어댑터 설계

## 목표와 범위

영림 OMS 원장 문서를 기존 `local_file_processor`가 생성하는 30열 원장 행에서 현재 Google Sheet Hub가 수용하는 22열 견적형 행으로 변환한다. 이번 단계는 순수 어댑터와 단위 테스트까지만 포함하며 `run_server.py`, 다운로드 주기, Google Sheet 연결은 변경하지 않는다.

## 공개 인터페이스

새 모듈 `ledger_file_processor.py`는 다음 공개 함수를 제공한다.

```python
map_ledger_to_estimate_schema(rows) -> list[list]
```

- 입력은 기존 원장 파서가 반환한 행들의 iterable이다.
- 출력은 각 행이 정확히 22개 셀인 새 목록이다.
- 입력 행을 변경하지 않는다.
- 빈 입력은 빈 목록을 반환한다.
- 짧은 행은 30열까지 빈 문자열로 패딩하여 안전하게 변환한다.

## 필드 매핑

| 출력 index | 의미 | 값 |
|---:|---|---|
| 1 | 거래처코드 | `00166` |
| 2 | 거래처명 | `기타매출처/doo` |
| 3 | 일자 | 입력 index 0 |
| 5 | 표시담당자 | `두현숙` |
| 14 | 품목코드 | 입력 index 17 |
| 15 | 품목명 | 입력 index 16 |
| 16 | 수량 | 입력 index 18 |
| 18 | 공급가액 | 입력 index 19 |
| 21 | 비고 | 입력 index 29 |
| 그 외 | 미사용 | 빈 문자열 |

VAT 분리, 세액 계산, 합계 계산, 문서 종류별 금액 분기는 추가하지 않는다.

## 테스트 경계

테스트는 공개 함수만 호출한다. 내부 헬퍼나 Google Sheets API는 테스트하지 않는다.

필수 행위:

1. 대표 30열 원장 행이 정확한 22열 값으로 변환된다.
2. 고정 거래처와 담당자 값이 설정된다.
3. 금액은 공급가액으로 단순 이동하며 VAT와 합계는 빈값이다.
4. 비고가 V열로 이동한다.
5. 빈 입력은 빈 목록이다.
6. 짧은 행도 예외 없이 22열로 변환된다.
7. 여러 입력 행의 순서와 행 수가 보존된다.
8. 입력 행은 변경되지 않는다.

## 오류 및 데이터 정책

어댑터는 외부 I/O를 수행하지 않는 결정적 순수 함수로 둔다. 입력 셀 값은 문자열 변환이나 금액 계산 없이 그대로 옮긴다. 행이 리스트가 아닌 명백히 잘못된 입력의 처리까지 확장하지 않으며, 이번 범위에서는 iterable 안의 시퀀스 행을 계약으로 한다.

## 비범위

- `run_server.py` 통합
- 30분 주기 변경
- 신규 Google Sheet 인스턴스 생성

- 원장 HTML 파서 변경
- 기존 견적 파이프라인 변경
- VAT·세액·합계 계산
