## 📸 상세 증거 자료 (Evidence)

### S1. .env Validation
`.env` 파일을 제거한 상태로 실행 시, `Config` 클래스에서 필수값을 즉시 체크하여 경고를 출력합니다.
```text
⚠️  WARNING: Missing critical environment variables in .env: ECOUNT_COMPANY_CODE, ECOUNT_ID, ECOUNT_PASSWORD
Action: Please check your .env file or .env.v10.example
```

### S2. Browser Audit
Edge 브라우저(`start_edge_debug.bat`)가 실행되지 않은 상태에서 서버 가동 시, 시작 단계에서 이를 감지합니다.
```text
[Server] Verifying browser connection...
[ERROR] Edge is not running on port 9333. Please run start_edge_debug.ps1 first!
⚠️ Browser NOT detected. Please ensure Edge is running with start_edge_debug.bat
```

### S3. Normal Operation
브라우저와 서버가 정상적으로 연결된 상태의 로그입니다. (app_20260223.json 발췌)
```json
{"timestamp": "2026-02-23T14:02:15", "level": "INFO", "message": "[Server] Verifying browser connection..."}
{"timestamp": "2026-02-23T14:02:17", "level": "INFO", "message": " ✅ Browser connection verified"}
{"timestamp": "2026-02-23T14:02:18", "level": "INFO", "message": "[Downloader] Starting cycle..."}
```

### S4. Browser Crash Handling
실행 도중 브라우저가 강제로 종료되었을 때, 다음 사이클이나 헬스체크에서 이를 감지하고 복구(Recovery)를 시도합니다.
```json
{"level": "ERROR", "message": "[Browser] Edge connection lost or crashed"}
{"level": "WARNING", "message": "[Downloader] Running aggressive recovery..."}
{"level": "INFO", "message": "[Downloader] Aggressive auto-recovery completed"}
```

V10 시스템은 이제 **초기 설정 오류, 외부 프로세스 유실, API 예외** 상황에서도 사용자에게 명확한 가이드를 제시하거나 스스로 독립(Standalone) 모드로 전환하여 시스템 전체의 정지를 방지하는 견고함을 갖추었습니다.
