# 영림 주문 자동화 시스템 주요 기능

현재 시스템은 ERP 직접 자동입력보다 **Google Sheet Hub 중심 운영 흐름**을 기준으로 동작합니다.

## 1. 시스템 구성 요소
- **메인 서버 (`v10_auto_server.py`)**: Flask 대시보드와 API 제공
- **파일 변환 엔진 (`local_file_processor.process_html_content()`)**: HTML/MHTML 주문 데이터를 ERP 형식 행 데이터로 변환
- **시트 허브 (`google_sheet_hub.py`)**: `Sheet1`, `Sheet2`, `Sheet3` 저장 및 상태/락 관리
- **다운로더**: 영림 OMS에서 주문서/견적서 수집

---

## 2. 주요 기능

### 대시보드
- READY 건수, 완료 이력, 현재 처리 상태 확인
- 문서 유형별 `복사` / `완료` 버튼 제공
- 브라우저 상태, 로그인 상태, 다운로더 상태 표시

### 자동 다운로드
- 영림 OMS에서 HTML/MHTML 파일 자동 수집
- READY 상태 기반 후속 처리
- 중복 다운로드 최소화

### 데이터 변환
- `local_file_processor.process_html_content()`가 HTML을 분석해 ERP용 행 데이터 생성
- 품목 코드/규격/수량/비고 등 규칙 기반 변환 적용

### Google Sheet Hub 처리
- 변환 결과를 `Sheet1`에 자동 저장
- `복사` 실행 시 클립보드 복사 + 상태 `처리중`
- 5초 후 `Sheet2`에 append-only 누적 이력 저장
- `Sheet3`에 날짜/건수/파일명 로그 저장
- `완료` 실행 시 `Sheet1` clear + 상태 `완료` + 락 해제
- 1분 타임아웃 시 자동 락 해제

---

## 3. 운영 특징
- ERP 직접 자동업로드 경로는 레거시로 남아 있고 현재 기본 운영 경로는 아님
- 여러 PC에서 동시에 접근해도 `Sheet1` 상태 기반으로 충돌을 줄임
- 완료 이력과 로그를 시트에 남겨 운영 추적이 쉬움
