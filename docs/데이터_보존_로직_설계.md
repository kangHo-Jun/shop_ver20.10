# [Data Retention Logic] 하루 전 데이터 보존 및 과거 데이터 자동 삭제

시트10, 시트11의 데이터가 무분별하게 누적되는 것을 방지하기 위해, **"오늘"과 "어제" 데이터만 유지**하고 그 이전 데이터는 자동으로 삭제하는 로직을 설계합니다.

## Proposed Logic (정리)

### 1. 기준 날짜 설정
- **Today (오늘)**: `new Date()`를 기준으로 생성된 `yyyy/MM/dd` 문자열
- **Yesterday (어제)**: `new Date()`에서 24시간을 뺀 날짜 기준의 `yyyy/MM/dd` 문자열

### 2. 필터링 프로세스
1. 시트의 전체 데이터를 읽어옵니다.
2. 각 행의 **첫 번째 열(A열, 날짜)** 값을 확인합니다.
3. 해당 값이 `오늘` 또는 `어제`와 일치하는 행만 추출합니다.
4. 추출된 데이터만 시트에 다시 덮어씌웁니다 (또는 기존 데이터를 지우고 새로 씁니다).

### 3. 적용 시점
- `automateEstimateParsing()` 함수 실행 시, 새로운 데이터를 추가하기 **직전**에 기존 데이터를 정리하는 함수(`cleanupOldData`)를 호출합니다.
