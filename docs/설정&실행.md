# V10 시스템 설정 및 실행 가이드 (Advanced Guide)

이 문서는 V10 시스템을 새로운 환경에 구축하거나 다시 실행할 때 필요한 단계별 가이드를 제공합니다. 최신 터미널 기반 실행 방식과 문제 해결 방법을 포함하고 있습니다.

---

## 🛠 1단계: 사전 준비 (Preparation)

### 1-1. 환경 변수 설정 (`.env`)
루트 폴더의 `.env.v10.example` 파일을 복사하여 `.env` 파일을 생성하고 다음 정보를 입력합니다.
> [!IMPORTANT]
> Ecount 계정 정보가 정확하지 않으면 자동 로그인 단계에서 타임아웃 오류가 발생합니다.

| 변수명 | 설명 |
| :--- | :--- |
| `ECOUNT_COMPANY_CODE` | 회원사코드 (6자리 숫자) |
| `ECOUNT_ID` | ERP 아이디 |
| `ECOUNT_PASSWORD` | ERP 패스워드 |
| `GS_SPREADSHEET_ID` | 분산 락 시트로 사용할 구글 시트의 ID |
| `ENABLE_DISTRIBUTED_LOCK` | 분산 락 사용 여부 (기본값: `false` - 단독 모드) |

### 1-2. 구글 API 인증서 배치
- 구글 클라우드 콘솔에서 발급받은 **`google_oauth_credentials.json`** 파일을 프로젝트 루트 폴더에 놓습니다. (분산 락 사용 시 필수)
- 최초 실행 시 브라우저를 통한 Google OAuth 승인이 1회 필요합니다.

---

## ⚙ 2단계: 시스템 설정 (Configuration)

### 2-1. 브라우저 경로 및 프로필 확인
- **`start_edge_debug.bat`** 파일은 시스템 환경변수(`%LOCALAPPDATA%`)를 사용하여 사용자의 Edge 프로필을 자동으로 탐지하도록 최적화되어 있습니다.

### 2-2. 수동 로그인 세션 확보 (중요)
- `start_edge_debug.bat`을 실행하여 브라우저를 띄웁니다.
- 열린 브라우저에서 **영림 OMS 사이트**에 접속하여 수동으로 로그인합니다.
- "로그인 유지"를 선택하여 브라우저 종료 후에도 로그인이 유지되도록 합니다. (서버가 이 세션을 재사용합니다.)

### 2-3. 필수 라이브러리 및 가상환경 설치
- 터미널에서 아래 명령어를 실행하여 가상환경을 구축하고 라이브러리를 설치합니다.
```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\pip install -r requirements.txt
```

## 🚀 3단계: 실행 및 확인 (Execution & Verification)

### 3-1. 실행 순서 및 터미널 명령어 (Terminal Commands)

시스템을 완전히 초기화하고 순서대로 실행하려면 터미널(CMD/PowerShell)에서 다음 명령어를 차례대로 입력하세요.

| 순서 | 명령어 | 목적 | 비고 |
|:---:|:---|:---|:---|
| **Step 1** | `.\kill_processes.bat` | 기존 프로세스 정리 | 실행 중인 Python 및 충돌 프로세스 일괄 종료 |
| **Step 2** | `.\start_edge_debug.bat` | Edge 디버그 모드 실행 | **필수:** 자동화 제어용 브라우저(Port 9333) 시작 |
| **Step 3** | `.\run_v10_server.bat` | V10 자동화 서버 실행 | 가상환경 활성화 후 서버(Port 5080) 구동 |

### 3-2. 정상 작동 확인
- **대시보드 접속**: [http://localhost:5080](http://localhost:5080)
- **상태 체크**: 
  - `Lock Manager: ✅ Connected` (단독 모드 시 `Standalone`)
  - `Browser Healthy: ✅`
  - `youngrim_logged_in: True`

## 🆘 문제 해결 (Troubleshooting)

| 현상 | 원인 및 해결 방법 |
| :--- | :--- |
| **"지정된 경로를 찾을 수 없습니다"** | `.venv` 폴더가 없거나 배정된 경로가 잘못됨. `Step 2-3`을 실행하여 가상환경을 재생성하세요. |
| **로그인 타임아웃/실패** | `.env`의 계정 정보 오류 또는 팝업 차단 발생. 브라우저에서 직접 로그인 후 재시도하세요. |
| **포트 충돌 (5080/9333)** | `.\kill_processes.bat`을 실행하여 잔류 프로세스를 강제 종료하세요. |
| **데이터 다운로드 안됨** | Edge 브라우저가 디버그 모드(Port 9333)로 정상 실행되었는지 확인하세요. |
| **모든 항목 스킵됨 (Locked)** | `google_oauth_credentials.json` 파일이 없는데 `ENABLE_DISTRIBUTED_LOCK`이 `true`인 경우 발생. `.env`에서 `false`로 변경하세요. |

> [!TIP]
> 모든 프로세스가 꼬였을 때는 `start_all.bat`을 실행하여 전체 과정을 한 번에 초기화 및 재시작할 수 있습니다.
