## 다운로드 문서 파싱 계약

기존 `local_file_processor.parse_html_table()`은 다음 순서로 원본 행을 읽는다.

1. NO
2. 색상
3. 품명
4. 규격
5. 수량
6. 단가
7. 금액
8. 비고

파서는 우선 `table.table-item`을 찾고, 없으면 모든 `table`을 대체 탐색한다. 숫자 NO로 시작하는 데이터 행만 처리하며 합계 행은 제외한다.

실제 원장 HTML 샘플 파일은 저장소에 아직 전달되지 않았으므로, 테이블 `id`와 실제 2~3개 데이터 행은 샘플 확보 후 이 문서에 추가해야 한다.

## 기존 원장 파서 출력

`local_file_processor.process_html_content(..., target_type="ledger")`는 30열 행을 반환한다.

| 원장 위치 | 값 |
|---|---|
| A / index 0 | 날짜 |
| G / index 6 | 고정값 `100` |
| Q / index 16 | 품목명 |
| R / index 17 | 품목코드 |
| S / index 18 | 수량 |
| T / index 19 | 금액 |
| AD / index 29 | 비고 |
| 나머지 | 빈값 |

## 스키마 갭

현재 `GoogleSheetHub`는 견적 행의 O/P/Q 위치를 기준으로 품목코드, 품목명, 수량을 읽는다. 원장 30열 행을 그대로 전달하면 원장 값은 Q/R/S에 있어 모든 행이 미매핑으로 분류된다.

원장 어댑터는 다음처럼 22열 계약으로 변환해야 한다.

| 원장 입력 | 22열 출력 | 처리 |
|---|---|---|
| A 날짜 | D 일자 | 이동 |
| R 품목코드 | O 품목코드 | 이동 |
| Q 품목명 | P 품목명 | 이동 |
| S 수량 | Q 수량 | 이동 |
| T 금액 | S 공급가액 | 그대로 이동 |
| AD 비고 | V 비고 | 이동 |
| 없음 | B 거래처코드 | `00166` 고정 |
| 없음 | C 거래처명 | `기타매출처/doo` 고정 |
| 없음 | F 표시담당자 | `두현숙` 고정 |

금액은 별도 VAT 계산이나 세액 분리 없이 원장 T 값을 출력 S 공급가액에 그대로 둔다. 그 밖의 열은 빈값이다.
