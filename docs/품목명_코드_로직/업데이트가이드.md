# 품목명/코드 로직 업데이트 가이드

## 1. 사전 준비 (Preparation)
1. 현재 git 상태 확인: `git log --oneline -5` / `git tag -l`
2. 작업 전 baseline 커밋+태그: `git add . && git commit -m "chore: vX baseline" && git tag vX-baseline`

## 2. 수정 절차 (Process)
1. `docs/품목_코드생성로직.md` 열어 현재 로직 파악
2. `docs/품목생성_코드생성_업데이트.md` 열어 목표 로직 파악
3. 두 문서 비교 → 차이점(누락/불일치) 확인
4. 대상 파일: `GAS_Source/code_generation.gs`
5. 수정 전 현재 코드 공유 후 수정 진행
6. 검증 케이스 전체 PASS 확인

## 3. 수정 후 체크리스트 (Post-update Checklist)
- [ ] 검증 케이스 전체 PASS
- [ ] `docs/품목_코드생성로직.md` 수정사항 + 날짜 업데이트
- [ ] git commit (push 제외)

## 4. 주요 파일 위치 (Main Files)
| 파일 | 설명 |
|------|------|
| `GAS_Source/code_generation.gs` | 품목명/코드 생성 핵심 로직 |
| `docs/품목_코드생성로직.md` | 현재 로직 기준 문서 |
| `docs/품목생성_코드생성_로직정리.md` | 목표 로직 기준 문서 |

## 5. 주요 함수 (Key Functions)
| 함수명 | 역할 |
|---------|------|
| `preprocessColorForProductName` | 품목명용 색상 전처리 |
| `generateBrandColorCode` | 브랜드/색상 코드 생성 |
| `classifyTarget` | 품목 분류 (문틀/문짝/레일/몰딩) |
| `generateFlagCode` / `generateModelCode` | 분류별 플래그/모델 코드 |
| `generateSpecCode` | 규격 코드 |

## 6. 주의사항 (Precautions)
- GAS 파일 수정은 서버 재시작 불필요 (저장 즉시 적용)
- git push 는 지시 있을 때만 실행
- 수정 전 반드시 baseline 커밋 먼저 진행
