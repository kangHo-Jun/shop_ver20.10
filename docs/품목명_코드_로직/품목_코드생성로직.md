## 1. 품목명 생성 흐름 (Product Name Generation)

품목명은 사용자가 읽기 좋은 형태로 데이터를 정형화하는 프로세스입니다.

### [입력 → 전처리 → 조합 → 출력]

1.  **입력 (Input)**: HTML에서 추출된 원본 데이터 (`colorRaw`, `itemNameRaw`, `specRaw`)
2.  **전처리 (Preprocessing)**:
    -   `preprocessColorForProductName`: 영림{숫자} 패턴 보호 및 불필요한 회사 키워드 제거
    -   `preprocessItemNameForProductName`: "문틀", "(식기X)" 삭제 및 `40MM평판` → `평40` 등 핵심 키워드 축약
    -   `preprocessSpecForProductName`: `/ N` → `식기무`, `/ S` → `식기유` 등 가독성 변환
3.  **조합 (Composition)**:
    -   `shouldAddCompanyPrefix`: 색상이나 품명에 이미 회사명이 포함되었는지 체크 후 없을 경우에만 접두사 추가
    -   `[접두사][색상] [품명] [규격]` 형태로 결합 (공백 처리 포함)
4.  **출력 (Output)**: 정제된 품목명 (예: `예림영림116 평40 2100*140`)

### FRAME 분기 참고 코드

```javascript
function 생성_품목명(colorRaw, itemNameRaw, specRaw, companyInfo) {
  const colorProcessed = preprocessColorForProductName(colorRaw);
  const itemNameProcessed = preprocessItemNameForProductName(itemNameRaw, specRaw);
  const specProcessed = preprocessSpecForProductName(specRaw);
  const classification = classifyTarget(itemNameRaw);

  const needsCompanyPrefix = shouldAddCompanyPrefix(
    colorProcessed,
    itemNameProcessed,
    companyInfo.display
  );
  const companyPrefix = needsCompanyPrefix ? companyInfo.display : '';

  if (classification === 'FRAME') {
    return `${companyPrefix}${colorProcessed} ${itemNameProcessed} ${specProcessed}`.trim();
  } else {
    return `${companyPrefix}${colorProcessed} ${itemNameProcessed} ${specProcessed}`.trim();
  }
}
```

### classifyTarget() 참고 코드

```javascript
function classifyTarget(itemName) {
  const itemStr = itemName.toString().trim();
  
  // 문틀 키워드
  const frameKeywords = ['문틀', '발포', '분리형', '스토퍼'];
  const hasFrame = frameKeywords.some(kw => itemStr.includes(kw));
  
  // 문짝 키워드
  const doorKeywords = ['문짝', 'ABS', '도어', 'M/D', '민무늬', '탈공', '미서기', '미닫이'];
  const hasDoor = doorKeywords.some(kw => itemStr.includes(kw));
  
  // 문짝 패턴
  const doorPatterns = /YS-[A-Z0-9]+|YA-[A-Z0-9]+|YAT-[A-Z0-9]+|EZ-[A-Z0-9]+|LS-[A-Z0-9]+|YM-[A-Z0-9]+|YAL-[A-Z0-9]+|YV-[A-Z0-9]+|YFL-[A-Z0-9]+|SW-[A-Z0-9]+|TD-[A-Z0-9]+|SL-[A-Z0-9]+/;
  const hasDoorPattern = doorPatterns.test(itemStr);
  
  // 연동 키워드
  const hasYeondong = /\d+연동/.test(itemStr);
  
  // 레일 키워드
  const hasRail = itemStr.includes('레일');
  
  // 몰딩 키워드
  const moldingKeywords = ['몰딩', '평', '코너', '계단', '천정', '천장', '걸레', '문선', '보드', '루버', '루바', '기둥'];
  const hasMolding = moldingKeywords.some(kw => itemStr.includes(kw));
  
  // 우선순위: 문틀 > 레일 > 문짝 > 몰딩
  if (hasFrame) {
    return 'FRAME';
  }
  
  if (hasRail && !hasDoor && !hasDoorPattern) {
    return 'RAIL';
  }
  
  if (hasDoor || hasDoorPattern || hasYeondong) {
    return 'DOOR';
  }
  
  if (hasMolding) {
    return 'MOLDING';
  }
  
  return 'NONE';
}
```

## 2. 코드 생성 흐름 (Product Code Generation)

핵심 비즈니스 로직으로, ERP 시스템에서 사용하는 고유 식별 코드를 생성합니다.

### [입력 → 분류 → 각 코드 생성 → 조합 → 출력]

1.  **분류 (Classification)**: `classifyTarget` 함수를 통해 품목의 카테고리 결정 (FRAME, DOOR, RAIL, MOLDING)
2.  **각 코드 생성 (Sub-code Generation)**:
    -   `generateBrandColorCode`: 브랜드 1자리 + 색상 2~4자리 코드 생성 (예: `Y116`, `yS50`)
    -   `generateFlagCode`/`ModelCode`/`RailCode`: 각 카테고리별 특성 코드 추출 (예: `NB`, `YA100`)
    -   `generateSpecCode`/`MoldingSpecCode`: 규격 숫자를 조합하여 코드 생성 (예: `2100140`, `4012`)
3.  **조합 (Composition)**: `brandColorCode` + `flagModelCode` + `specCode`
4.  **출력 (Output)**: 최종 ERP 품목코드 (예: `y116NB2100140`)

## 3. 분류 및 우선순위 (Classification Priority)

`classifyTarget` 함수는 키워드 매칭을 통해 순차적으로 분류를 시도하며, 상위 순위에 매칭되면 즉시 반환합니다.

| 순위 | 분류 (Category) | 주요 키워드 및 패턴 |
| :--- | :--- | :--- |
| **1** | **문틀 (FRAME)** | 문틀, 발포, 분리형, 스토퍼 (단일 키워드 우선) |
| **2** | **레일 (RAIL)** | 레일 키워드 포함 (문짝 패턴이 없을 것) |
| **3** | **문짝 (DOOR)** | 문짝, ABS, 도어, YS-, YA-, LS-, 연동 패턴(`\d+연동`) |
| **4** | **몰딩 (MOLDING)** | 몰딩, 평, 코너, 계단, 걸레받이, 루바, 기둥 |

---

## 4. 주요 패턴 및 정규식 (Regex Patterns)

| 구분 | 정규표현식 | 설명 |
| :--- | :--- | :--- |
| **색상-영림** | `/영림(\d+)PS\d+/` | 영림 번호와 PS 번호가 섞인 경우 영림 번호만 추출 |
| **색상-한글** | `/^[가-힣\s]+$/` | 한글만 있는 경우 앞 2글자만 추출하여 코드화 |
| **문짝-모델** | `/([A-Z]+)-([A-Z0-9]+)/` | `YA-100` 형태의 모델명에서 하이픈 제거 후 추출 |
| **몰딩-평판** | `/(\d+)MM평판?/` | 평판의 두께(MM) 정보를 추출하여 품목명/코드에 활용 |
| **규격-숫자** | `/\d+/g` | 문자열에서 모든 숫자만 추출하여 결합 (규격코드용) |

## 5. 입출력 예시 (Examples)

### 1) 문틀 (FRAME)
-   **입력**: 색상:`영림116`, 품명:`발포문틀`, 규격:`2100/140/N`
-   **품목명**: `예림영림116 발포 2100/140식기무`
-   **품목코드**: `y116NB2100140` (y + 116 + NB + 2100140)

### 2) 문짝 (DOOR)
-   **입력**: 색상:`영림50`, 품명:`YA-100 ABS도어`, 규격:`900*2100`
-   **품목명**: `예림영림50 YA-100 900*2100`
-   **품목코드**: `y50YA1009002100` (y + 50 + YA100 + 9002100)

### 3) 몰딩 (MOLDING)
-   **입력**: 색상:`중백색`, 품명:`40MM평판`, 규격:`(40*9)`
-   **품목명**: `예림중백색 평40 (40*9)`
-   **품목코드**: `y중백평40` (y + 중백(2글자) + 평 + 40)

## 5. 데이터 보존 및 자동 삭제 (Data Retention)

ERP 업로드용 데이터가 무분별하게 누적되는 것을 방지하기 위해 자동 청소(Cleanup) 로직이 적용되어 있습니다.

- **보존 원칙**: 실행 시점의 **오늘(T)**과 **어제(T-1)** 데이터만 유지.
- **작동 방식**: 
    1. `cleanupOldData` 함수가 A열(날짜)을 전수 조사.
    2. 오늘/어제와 일치하지 않는 행은 배열에서 제외.
    3. 필터링된 기존 데이터 뒤에 새 데이터를 결합하여 시트에 다시 기록.
